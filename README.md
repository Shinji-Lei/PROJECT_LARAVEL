# Task Manager (Laravel)

Project Code: WST21-PM-2026-SF

Student Name: Calvo Shinji lei

Course & Year: BSIT-2 SEC-1

Database Used: MySQL

-----Features------
- Add Task
- View Tasks
- Edit Task
- Delete Task
- Update Status

-----Setup-----
1. XAMP `run the apache and mysql`
2. Vs Code
3. install`composer install`.
4. Copy `.env.example` to `.env` and set your database credentials.
5. Run `php artisan key:generate`.
6. Run `php artisan migrate`.
7. Run `php artisan serve` and visit `http://127.0.0.1:8000`.
